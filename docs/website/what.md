# What Is a Bear?

A Bear is not just a chatbot, and not just a language model. A Bear is a model given a role to perform, a place to perform it, memory from prior scenes, tools it can safely use, and a surrounding harness that helps it keep continuity over time.

For the public story, this can be explained through a theater metaphor.

## The Actor

The model is the performer: it speaks, reasons, improvises, explains, and responds in the moment. But the actor alone is not the whole production.

## The Role

A Bear has a durable purpose. Its charter defines what kind of responsibility it carries, what it should pay attention to, and where its boundaries are.

## The Stage

Every interaction happens somewhere: in a conversation, a project, a task, a workspace, or a shared mission. The stage gives the Bear its immediate situation.

## The Script Notes

The Bear carries forward memory: facts, preferences, prior decisions, working context, and lessons that should matter again later. These notes keep the Bear from starting from zero every time.

## The Props

A Bear can use tools. It may search memory, fetch information, read or edit files, inspect state, or take other permitted actions. Tools are how the Bear reaches beyond conversation into work.

## The Stage Manager

Den is the harness behind the scene. It assembles the Bear's identity, context, memory, tools, permissions, and runtime environment so the performance can happen safely and coherently.

## The Ensemble

Bears work with humans, other Bears, and shared Cabinet Missions. A Bear is not only an individual assistant; it can participate in coordinated work.

## Rehearsal and Review

A Bear can improve over time. Reflection, review, and curation help turn experience into cleaner memory, better habits, and more useful future behavior.

## Working Definition

A Bear is a durable AI collaborator: a model performing a defined role inside a governed harness, with memory, tools, relationships, and continuity.
