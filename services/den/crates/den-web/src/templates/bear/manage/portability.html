Portability

A Bear is its curated memory and configuration — not its transcripts. Export produces a bundle you can carry to another Den; this server keeps its own record.

Export

Download bundle (.bear)

The bundle contains identity, configuration, and the Bear's canonical SQLite memory as of this moment. Anything the reflection lanes have not yet curated into memory stays behind in this Den's transcripts.

What moves, what stays

Concern In the bundle?
Identity, charter, stance configurationYes
Canonical memory (all scopes), promotions, proposalsYes
Conversations and transcriptsNo — stay on this Den
Jobs, runs, approvals in flightNo — stay on this Den
Membership (people)No — re-granted on the target
Connections, tokens, secretsNever — re-attached on the target
Recall index (derived)No — rebuilt from memory on import
